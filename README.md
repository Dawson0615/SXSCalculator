# SXS XP Calculator

A mobile-friendly XP calculator that estimates:

- XP and time remaining until the next level
- Total XP and time remaining until a selected wanted level
- Current progress within the active level

## Inputs

- Season
- Current level
- Wanted level
- Current XP earned toward the next level
- Average XP gained per hour

## GitHub Pages

This is a static website. To publish it with GitHub Pages:

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.

The public site will be available at:

`https://dawson0615.github.io/SXSCalculator/`

## Data source

XP requirements are stored in `assets/data/exp_required.json` and sourced from:

https://qenu.github.io/ethna-timeline/assets/data/exp_required.json

This is an unofficial community tool.
